# Chinese Study Plan Skill for Claude Code

帮助高中生制定高考学习计划的 Claude Code Skill，支持逆推式学习计划生成。

## 使用场景

- **制定学习计划**：根据当前分数和目标院校，生成逆推式学习计划
- **逆推规划**：从高考目标倒推到每周/每日的具体任务
- **两阶段学习**：区分知识学习期和提分期，策略分明

## 安装

```bash
# 方式一：复制到 ~/.claude/skills/
git clone https://github.com/zimvir/chinese-study-plan-skill.git
cp -r chinese-study-plan-skill ~/.claude/skills/chinese-study-plan-skill

# 方式二：直接在项目目录使用
cd chinese-study-plan-skill
claude  # 在项目目录下启动 Claude Code
```

## 命令

| 命令 | 描述 |
|------|------|
| `/plan-ch-study` | 触发学习计划制定 |
| 帮我做学习计划 | 自然语言触发 |

## 工作流 & 示例

### 阶段1：触发 Skill
```
/plan-ch-study
```

或直接说：
```
帮我做一下这个学期的学习计划
```

### 阶段2：回答问题

Skill 会依次问你：

1. 你现在的各科分数是多少？
2. 你的目标院校或目标分数是什么？
3. 你每天什么时候到家？到家后能学习多长时间？
4. 你哪科比较擅长、哪科比较吃力？

### 阶段3：确认大纲

你会得到这样的计划大纲：

```markdown
# 学习计划大纲

## 逆推总框架
2028/6 高考689+
         ↓
2028/3 全力冲刺
         ↓
2027/8 知识全部学完
         ↓
...

## 各科分数逆推
| 时间 | 数学 | 英语 | ... | 总分 |
|------|------|------|------|------|
| 今天 | 50 | 65 | ... | 373 |
| 高考 | 125 | 125 | ... | 689+ |

## 两阶段框架
### 阶段一：知识学习期（今天 ~ 2027/8）
### 阶段二：提分期（2027/8 ~ 2028/6）

## 里程碑检查点
| 时间 | 目标 | 验证方式 |
```

### 阶段4：生成每周详细计划

确认大纲后，Skill 会生成：
- 每周 MIT（最重要的3件事）
- 每日执行时间表
- 周末复习模板
- 里程碑周检查点

```
└── references/

    └── knowledge/                  ← 知识库（RAG）
```

## 核心方法论

**逆推式规划**：从高考目标倒推到今天的每周任务

**两阶段框架**：
- 知识学习期：快速学完，建立框架，不刷题
- 提分期：刻意练习，专项突破，冲高分
