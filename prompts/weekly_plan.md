# 任务
根据已确认的大纲，生成每周详细执行计划

## 输入
- Step 2 确认的大纲（各科目标分数、两阶段框架、里程碑）
- 用户实际可用的时间（每日时长、每周哪天可全天学习）

## Step 1 计算每周任务量

基于大纲中的时间节点，计算：
- 距离高考总周数
- 每个阶段需要覆盖的内容
- 每周需要推进的进度

## Step 2 生成周计划模板

### 每日执行模板（周一至周五）

根据用户实际时间情况填写，例如（具体输出按用户实际情况讨论）：

```
[用户到家时间]  编程/工作结束
       ↓
[用户到家时间+5分钟]  写下今晚3个MIT
       ↓
[MIT ①时间块]  执行第1个MIT（[优先级最高的科目]）
               → 打开教材，定位目标页
               → 边读边用自己的话总结
               → 闭卷回忆：核心公式是什么？
       ↓
[MIT ②时间块]  执行第2个MIT（[次优先级科目]）
               → App背单词 / 看完一节 / 做课后习题
       ↓
[MIT ③时间块]  执行第3个MIT（[轮换科目]）
               → 看完一节，做课后习题
       ↓
[最后10分钟]  主动回忆
               → 闭卷回忆今日3个核心点
       ↓
[最后5分钟]  记录
               ↓
[睡觉时间]  睡觉
```

### 周末执行模板

**周六全天（推荐）**
- 上午：[科目A] 本周知识复习
- 下午：[科目B] 本周知识复习
- 晚上：[科目C] 精读/词汇

**周日晚上**
- 回顾本周各科进度
- 制定下周3个MIT
- 估算下周时间
- 预留缓冲

## Step 3 输出周计划

### 输出格式

```markdown
# [阶段名] 每周计划

## 逆推总框架
[从高考目标到今天的逆推时间线]

---

## 第X周（日期）
├── 数学：
├── 物理：
├── 化学：
├── 英语：
└── 记录：今日MIT完成情况

## 第X周
...

## 每周固定流程
周日晚上：
├── 回顾本周各科进度
├── 制定下周3个MIT
├── 估算下周时间
└── 预留缓冲

## 里程碑周

| 周次 | 时间 | 目标 |
|------|------|------|
| 第1周 | | 启动，3个MIT习惯建立 |
| 第X周 | | |
```

## 核对清单

在输出每周计划前，确认以下都已包含：
- [ ] 每周3个MIT（数学优先）
- [ ] 每日时间分配（数学40分钟 + 英语25分钟 + 物理/化学20分钟 + 主动回忆10分钟）
- [ ] 周末执行模板（周六全天 + 周日晚上计划制定）
- [ ] 里程碑周（关键节点检查）
- [ ] MIT记录模板（可打印/手写）
