# Step 2 输出格式模板

核对清单：输出前确认以下6部分都已包含
- [ ] 靶子确认：目标分数、目标院校、差距
- [ ] 差距拆解：各科分数逆推表
- [ ] 时间分配：两阶段起止时间
- [ ] 第一阶段里程碑：知识期的关键节点
- [ ] 风险提示：计划中的主要风险点
- [ ] 确认后进入：告诉用户"确认后进入Step 3生成每周详细计划"

> 方法论参考：两阶段框架详见 `references/two_study_stage.md`
